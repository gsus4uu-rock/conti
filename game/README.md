# 엘드리아 연대기 (Chronicles of Eldria)

선택지로 진행하는 도트 판타지 RPG. 서버 없이 브라우저만 있으면 돌아갑니다.

## 이 게임의 운영 구조 (중요)

이 게임은 **완결이 없습니다.** 아버지가 운영자로서 계속 이야기를 열어 주는 구조입니다.

```
아이가 플레이  →  진행 상황이 아빠에게 보임  →  아빠가 선물/새 지역을 보냄
        ↑                                                    │
        └────────────────────────────────────────────────────┘
```

- **`game/admin.html`** = 운영자실. 아이별 레벨·아이템·칭호·전투 기록을 보고, 우편함으로 선물을 보냅니다.
- 지금 열려 있는 곳은 **제1장 「속삭이는 숲」** 뿐입니다. 다음 장은 아버지가 열어 줄 때까지 잠겨 있습니다.
- 서버 설정 없이도 **코드를 카톡으로 주고받는 방식**으로 바로 운영됩니다.

설정 방법은 **`game/SETUP.md`** 에 있습니다.

## 실행 방법

- **그냥 열기**: `game/index.html` 을 더블클릭하면 바로 실행됩니다.
- **폰에서 하기**: GitHub Pages를 켜면 `https://<계정>.github.io/conti/game/` 로 접속됩니다.
  폰 브라우저에서 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있습니다.

저장은 브라우저(localStorage)에 자동으로 됩니다.
기기를 옮길 때는 마을 → `저장 / 설정` → `세이브 코드 내보내기` 로 코드를 복사해서
새 기기의 `세이브 코드 불러오기` 에 붙여넣으면 됩니다.

```

   ├─ pixel.js         픽셀 렌더러 (이미지 파일을 쓰지 않음)
   ├─ scene.js         전투/마을/필드/이벤트 화면 구성
   ├─ game.js          엔진 (전투 계산, 성장, 저장, 확률, 불굴)
   ├─ ui.js            화면 흐름, 대사창, 선택지, 꿈 오프닝
   └─ data/
      ├─ items.js      ★ 아이템
      ├─ skills.js     ★ 스킬
      ├─ jobs.js       ★ 직업 (히든 직업 포함)
      ├─ growth.js     ★ 성장형 히든 무기 단계
      ├─ world.js      ★ 몬스터 / 지역 / 의뢰 / 챕터 설정
      └─ events.js     ★ 운명 이벤트 + 오프닝/아버지 편지
```

★ 표시된 파일만 건드리면 내용을 계속 늘릴 수 있습니다. 엔진은 안 만져도 됩니다.

## 세계관 요약

하늘에 붉은 균열 **「천공의 상처」** 가 난 세계, **엘드리아**.
500년 전 일곱 영웅이 마왕 **네로스** 를 그 안에 봉인했지만, 봉인이 약해지고 있습니다.

주인공은 **벨라온 마을** 에서 태어난 열다섯 살 아이.
태어나던 날 밤 별똥별이 떨어져서 "별을 삼킨 아이"라고 불립니다.
— 이것이 **낮은 확률로 주인공에게만 기적이 일어나는 이유**의 세계관적 설명입니다.

아버지 **가론**은 모험가였고, 천공의 상처를 조사하러 떠나 돌아오지 않았습니다.
게임 시작 시 촌장이 아버지가 남긴 편지를 건네줍니다.

**최종 목표**: 마왕 네로스 토벌 + 아버지 찾기 → **Lv.100 필요** (지금은 Lv.1)
아득히 멀다는 것을 `내 정보` 화면에서 늘 보여 줍니다.

### 오프닝

꿈에서 시작합니다. 최강 상태로 마왕 네로스와 싸우다가 — 눈을 뜨면 열다섯 살 소년의 침대입니다.
설정 설명을 길게 읽히지 않고, 전투 조작을 배우면서 최종 목표를 먼저 보여 주는 구성입니다.
(전체 오프닝 19클릭)

### 주인공 보정 「불굴」

쓰러질 공격을 맞아도 **전투당 한 번은 HP 1로 버팁니다.** 그리고 바로 다음 공격이 **3배(반격)** 가 됩니다.
소설 속 주인공이니까요. 측정해 보니 이 능력 덕분에 Lv.30까지 가는 동안 사망이 평균 0~3회로 줄었습니다.

### 성장형 히든 무기 「이름 없는 검」

Lv.4 이후 돈을 좀 모았을 때 낮은 확률로 **고물 수레의 노인**이 나타나 20 G짜리 고철 검을 팝니다.
사면 그 검이 **주인과 함께 자랍니다.** 전투에서 이길 때마다 검도 경험치를 얻습니다.

| 단계 | 이름 | 공격 |
|---|---|---|
| 1 | 이 빠진 낡은 검 | 4 |
| 2 | 손에 익은 검 | 14 |
| 3 | 녹을 벗은 검 | 32 |
| 4 | 이름을 되찾은 검 「여명」 | 58 |
| 5 | 여명 · 각성 | 92 |
| 6 | 여명 · 완성 | 150 |

단계가 오를 때마다 짧은 이야기가 나옵니다. 단계 추가는 `js/data/growth.js` 에 한 칸 넣으면 됩니다.

### 지역 (레벨 + 아버지의 개방)

| 지역 | 개방 | 내용 |
|---|---|---|
| 벨라온 마을 | 처음부터 | 상점 · 여관 · 의뢰 · 전직 |
| 마을 뒷들판 | Lv.1 | 슬라임 · 들쥐 · 뿔토끼 |
| 속삭이는 숲 | Lv.5 | 고블린 · 숲거미 · 회색늑대 / 보스 2종 |
| 무너진 광산 | Lv.13 | 코볼트 · 동굴박쥐 · 돌골렘 / 보스 1종 |
| 왕도 아르카스 | Lv.30 | 🔒 |
| 천공의 상처 | Lv.100 | 🔒 최종 목적지 |

**지금 열려 있는 것은 제1장(마을·들판·숲)까지입니다.**
레벨이 충분해도 챕터 밖은 잠깁니다 — 아버지가 열어 줄 때까지 기다립니다.
고블린 두목을 잡으면 제1장 완결 연출이 나오고, "다음 이야기는 준비 중"이라고 안내됩니다.

챕터를 여는 방법은 `SETUP.md` 의 "다음 장 열어 주기"를 보세요.

## 운명 이벤트 — 이 게임의 핵심

전투에서 이기거나 `주변을 둘러본다` 를 할 때마다 확률로 발생합니다.

| 등급 | 확률 | 성격 |
|---|---|---|
| **1 소소한 행운** | 약 15% | 골드·물약 정도. 선택지 없음 |
| **2 운명의 갈림길** | 약 5%~ | 선택지가 있고 결과가 갈림. 이야기의 본체 |
| **3 각성** | 약 0.4%~ | 히든 직업·전설 장비. 인생이 바뀜 |

오래 안 뜨면 확률이 조금씩 올라갑니다(천장). 아이가 "나만 안 뜬다"고 좌절하지 않도록.
등급 3은 **평균적으로 한 판에 1~2번**만 나오게 맞춰져 있습니다.

## 이야기 추가하는 법

### 1. 새 이벤트 (가장 자주 하실 작업)

`js/data/events.js` 의 `E` 배열에 객체 하나만 넣으면 끝입니다.

```js
{
  id: 'my_event',          // 겹치지 않는 이름
  tier: 2,                 // 1=행운 2=갈림길 3=각성
  once: true,              // 평생 한 번만 (빼면 여러 번 나옴)
  bg: 'forest',            // plains/forest/mine/night/ruin/town
  spr: 'guard',            // 가운데 띄울 그림 (sprites.js 의 이름, 생략 가능)
  cond: function (p) { return p.lv >= 10; },   // 등장 조건 (생략 가능)
  title: '이벤트 제목',
  pages: [
    '첫 문단.',
    '둘째 문단. 클릭하면 한 장씩 넘어갑니다.',
    '',                    // 빈 줄 = 줄바꿈하고 같은 장에 계속
    '이 줄은 위와 같은 장에 붙습니다.'
  ],
  choices: [               // 없으면 gain 만 적용됩니다
    {
      t: '선택지 문구',
      need: 'potion',      // 이 아이템이 없으면 선택 불가 (생략 가능)
      pages: ['고른 뒤 이야기.'],
      gain: { items: ['potion'], stat: { atk: 2 }, expByLv: 100 }
    }
  ]
}
```

**`gain` 에 쓸 수 있는 것**

| 키 | 뜻 |
|---|---|
| `gold` / `goldByLv` | 골드 (`goldByLv`는 레벨에 비례) |
| `goldHalf` | 가진 돈의 절반을 잃음 |
| `exp` / `expByLv` | 경험치 |
| `items: ['id', ...]` | 아이템 지급 |
| `useItem: 'id'` | 아이템 소모 |
| `stat: { atk: 3, hp: 50 }` | 영구 능력치 (hp/mp/atk/def/spd/luk) |
| `skill: 'id'` | 스킬 습득 |
| `job: 'id'` | 직업 변경 |
| `titleGet: '칭호'` | 칭호 획득 |
| `flag: '이름'` | 기록만 남김 (나중에 `cond` 에서 활용) |
| `heal: true` / `full: true` | 회복 |
| `damage: 0.5` | 최대 HP의 50%만 남기고 부상 |

> 각성(tier 3) 이벤트로 히든 직업을 주려면 `givesJob: true` 를 꼭 붙이세요.
> 그래야 "히든 직업은 평생 하나" 규칙이 지켜집니다.

### 2. 새 지역 열기

`js/data/world.js` 에 몬스터를 넣고 `REGIONS` 에 한 칸 추가하면 됩니다.

```js
// MONSTERS 에 추가
orc: { name: '오크', sprite: 'goblin', lv: 30, hp: 900, atk: 200, def: 70, spd: 14,
       exp: 600, gold: 300, drops: [['ore', 0.3]], flavor: '고블린보다 두 배는 크다.' },

// REGIONS 에 추가 (locked: true 를 지우면 열립니다)
{
  id: 'plateau', name: '바람의 고원', theme: 'plains', unlockLv: 27, seed: 51,
  monsters: ['orc'],
  boss: 'boss_orc', bossLv: 34,
  desc: '왕도로 가는 길목.',
  enter: '바람이 정면에서 불어왔다.'
}
```

레벨이 되면 **"◆◆ 새로운 지역이 열렸습니다 ◆◆"** 가 자동으로 뜹니다.

**새 지역 몬스터 수치 잡는 법** (아이가 지루하지도 좌절하지도 않는 선):
- 일반 몬스터: 적정 레벨에서 **3~5턴**에 잡히게
- 보스: **10~14턴**
- 플레이어가 버티는 시간: 잡는 데 걸리는 시간의 **1.5~2배**

대략 `HP ≈ 적정레벨 × 20`, `공격력 ≈ 적정레벨 × 5` 에서 시작해 조절하세요.

### 3. 새 도트 그림 그리기

`js/sprites.js` 에 글자로 그립니다. `.` 과 빈칸은 투명, 나머지는 팔레트 번호(0~f).

```js
S.orc = {
  p: [null, '#1e3a1e', '#5aa03c', '#8fd45c'],   // 0번은 반드시 null(투명)
  d: [
    '................',
    '.....111111.....',
    '....12222221....',
    // ... 16줄 (24x24 도 가능)
  ]
};
```

위아래에 빈 줄이 있어도 **자동으로 발판 위에 맞춰 세워집니다.**

### 4. 아버지의 편지 고치기

`js/data/events.js` 맨 아래 `STORY.fatherLetter` 배열이 편지 본문입니다.
첫 줄의 `'아들에게'` 는 게임에서 자동으로 **`(아이이름)에게`** 로 바뀝니다.

## 밸런스 조절 손잡이

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 레벨업을 빠르게/느리게 | `game.js` 의 `expNeeded()` |
| 운명 이벤트를 더 자주/드물게 | `game.js` 의 `rollFate()` 안 `c1` `c2` `c3` |
| 전투 난이도 | `world.js` 의 몬스터 `hp` / `atk` |
| 죽었을 때 벌칙 | `game.js` 의 `finishBattle()` (지금은 골드 10% 손실) |
| 직업별 성장 | `jobs.js` 의 `grow` |
