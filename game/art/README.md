# art — 그림을 여기에 넣으세요

파일을 넣으면 자동으로 코드 도트를 대체합니다. **한 장씩 넣어도 됩니다.**
파일이 없는 것은 그냥 원래 도트로 그려집니다.

```
art/
├─ bg/     배경  (480x270 비율, 권장 1920x1080)
│   plains.png  forest.png  mine.png  town.png  night.png  ruin.png
└─ spr/    캐릭터 (배경 투명 PNG, 권장 1024x1024)
    hero_front.png  hero_back.png
    slime.png  rat.png  hornrabbit.png
    goblin.png  spider.png  wolf.png
    kobold.png  bat.png  golem.png
    boss_goblin.png  boss_spider.png  boss_golem.png
    neros.png
    elder.png  merchant.png  guard.png
```

파일 이름은 **정확히** 위와 같아야 합니다.

프롬프트는 `game/ART_PROMPTS.md` 에 전부 정리해 두었습니다.
